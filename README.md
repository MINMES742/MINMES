# 个人主页

一个纯静态的个人主页：无框架、无构建步骤、无外部依赖，双击 `index.html` 即可打开。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `data.js` | **你的个人资料都在这里**：姓名、简介、技能、项目、联系方式 |
| `styles.css` | 样式；换整体配色只改 `:root` 里的颜色变量 |
| `main.js` | 渲染与交互逻辑，一般不需要修改 |

## 使用方法

1. 打开 `data.js`，把里面的占位内容换成你自己的信息。
2. 保存后用浏览器打开 `index.html`（或刷新已打开的页面）即可看到效果。

> 提示：`data.js` 里每项的末尾不要漏掉逗号。

## 功能

- 「关于 / 技能 / 项目 / 联系」单页导航，滚动时自动高亮当前区块
- 技能进度条，滚动到视口时从 0 平滑生长
- 深浅色主题切换，默认跟随系统，选择会记忆在浏览器本地
- 响应式布局，适配手机
- 支持 `prefers-reduced-motion`（减弱动画）与打印样式
- 页面内容全部由 `textContent` 写入，不拼接 HTML，避免注入风险

## 部署到 GitHub Pages

仓库 `Settings` → `Pages` → Source 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后访问：

```
https://<你的用户名>.github.io/MINMES/
```
